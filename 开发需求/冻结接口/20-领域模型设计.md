# 20-领域模型设计.md

# 一、领域模型总览

```text
Organization

├── Project
│
│   ├── Event
│   ├── Task
│   ├── Meeting
│   ├── File
│   └── Conversation
│
└── KnowledgePackage
      │
      └── Document
            │
            └── Chunk
```

---

# 二、Project（根聚合）

Project是整个系统核心。

所有业务对象必须挂载到Project。

```python
class Project:

    id:int

    code:str

    name:str

    status:str
```

---

# 三、Task

任务实体。

```python
class Task:

    id:int

    project_id:int

    title:str

    description:str

    assignee_id:int

    status:str

    due_date:date
```

状态：

```text
TODO

IN_PROGRESS

DONE

CANCELLED
```

---

# 四、Event

事件实体。

记录客观事实。

例如：

```text
现场放线完成

材料到场

样板验收通过
```

```python
class Event:

    id:int

    project_id:int

    content:str

    creator_id:int
```

---

# 五、Meeting

会议实体。

```python
class Meeting:

    id:int

    project_id:int

    title:str

    summary:str
```

会议不直接产生任务。

任务由Meeting解析流程生成。

class File:

# 七、KnowledgePackage

知识包。

系统核心资产。

```python
class KnowledgePackage:

    id:int

    name:str

    category:str
```

分类：

```text
项目知识包

设计导则包

标准图集包

工程经验包

供应商资料包

研究专题包
```

# 十二、领域原则

业务数据优先。

图谱数据其次。

原则：

```text
先沉淀业务资产

再构建知识资产

最后构建关系资产
```

这是TeamBrain长期演进路线。
