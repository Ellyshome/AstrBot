
## 数据结构设计
### 表1：通讯记录表 `im_message`
| 字段名          | 类型         | 约束规则 | 说明                                                                 |
|-----------------|--------------|----------|----------------------------------------------------------------------|
| id              | bigint       | 主键     | 消息唯一ID                                                           |
| conversation_id | varchar(64)  | 非空     | 会话ID（单聊/群聊）                                                   |
| sender_id       | bigint       | 非空     | 发送者ID                                                             |
| receiver_id     | bigint       | 可为空   | 接收者ID（单聊用）                                                   |
| group_id        | bigint       | 可为空   | 群ID（群聊用）                                                       |
| msg_type        | smallint     | 非空     | 消息类型 1=文本 2=图片 3=文件 4=语音 5=视频 6=卡片                  |
| content         | text         | 默认空串 | 消息内容（文本/JSON）                                                |
| file_url        | text         | 默认空串 | 文件/语音/视频 URL                                                   |
| status          | smallint     | 非空     | 消息状态 0=发送中 1=已发送 2=已送达 3=已读 4=撤回 5=失败            |
| created_at      | timestamp    | 非空     | 发送时间                                                             |

### 表2：人员信息表 `employee`
| 字段名          | 类型         | 约束规则 | 说明                                                                 |
|-----------------|--------------|----------|----------------------------------------------------------------------|
| id              | bigint       | 主键     | 员工唯一ID（雪花ID/自增）                                            |
| name            | varchar(32)  | 非空     | 姓名                                                                 |
| gender          | smallint     | 默认0    | 性别 0=未知 1=男 2=女                                                |
| id_card         | varchar(32)  | 默认空串 | 身份证号                                                             |
| phone           | varchar(20)  | 默认空串 | 手机号                                                               |
| email           | varchar(64)  | 默认空串 | 邮箱                                                                 |
| qq              | varchar(20)  | 默认空串 | QQ号                                                                 |
| wechat          | varchar(40)  | 默认空串 | 微信号                                                               |
| remark          | text         | 默认空串 | 人物备注（自然语言）                                                 |
| creator_id      | bigint       | 非空     | 创建人ID（谁把他加进来的）                                           |
| create_time     | timestamp    | 非空     | 创建时间                                                             |
| update_time     | timestamp    | 非空     | 更新时间                                                             |
| is_deleted      | boolean      | 默认false| 逻辑删除标记                                                         |
| perm_list       | text[]       | 默认空数组| 权限集                                                               |
| grouping          | smallint     | 默认0    | 性别 0=临时组 1=访客组 2= 工程组 3= 供货商 4=管理组                     |
| -               | -            | CHECK约束 | 【整体约束】四个联系方式不能同时为空，至少填写其中一个有效联系方式，约束规则：`CHECK (phone != '' OR email != '' OR qq != '' OR wechat != '')` |

| address                    | varchar(256) | 非空     | 项目详细地址                                                         |
| city                       | varchar(32)  | 非空     | 所属城市                                                             |
| creator_id                 | bigint       | 非空     | 创建人ID                                                             |
| create_time                | timestamp    | 非空     | 创建时间                                                             |
| update_time                | timestamp    | 非空     | 更新时间                                                             |
| is_deleted                 | boolean      | 默认false| 逻辑删除标记                                                         |
| 

### 表4：项目指标表 `project_indicator_details`
| 字段名             | 类型         | 约束规则 | 说明                                                                 |
|--------------------|--------------|----------|----------------------------------------------------------------------|
| id                 | bigint       | 主键     | 扩展指标唯一ID                                                       |
| project_id         | bigint       | 非空     | 所属项目ID，关联`project_indicators.id`                              |
| indicator_name     | varchar(64)  | 非空     | 指标名称（例如：抗震等级、装配式占比、装配率、海绵城市要求等）       |
| indicator_value    | varchar(128) | 非空     | 指标值（支持数字、文本、日期等任意格式的指标内容存储）               |
| unit               | varchar(32)  | 默认空串 | 指标单位（例如：%、m、MPa、年等）                                    |
| source_file_id     | bigint       | 可为空   | 来源文件ID，关联文件存储表，用于溯源指标来自哪个规划/批复/图纸文件   |
| description        | text         | 默认空串 | 指标说明（补充指标含义、适用场景、取值规则等内容）                   |
| is_constraint      | boolean      | 默认false| 是否强制指标                                                     |
| creator_id         | bigint       | 非空     | 创建人ID                                                             |
| create_time        | timestamp    | 非空     | 创建时间                                                             |
| update_time        | timestamp    | 非空     | 更新时间                                                             |
| is_deleted         | boolean      | 默认false| 逻辑删除标记                                                         |

### 表5：公司基础信息表 `company_info`
| 字段名              | 类型         | 约束规则 | 说明                                                                 |
|---------------------|--------------|----------|----------------------------------------------------------------------|
| id                  | bigint       | 主键     | 公司唯一ID                                                           |
| company_name        | varchar(128) | 非空     | 公司全称                                                             |
| unified_code        | varchar(32)  | 非空     | 统一社会信用代码（18位国家统一编码，公司唯一身份标识）               |
| business_desc       | text         | 默认空串 | 业务描述（公司经营范围、核心业务领域、资质等级等说明）               |
| project_leader_id   | bigint       | 非空     | 项目负责人ID，关联`employee.id`，指定负责对接该公司的内部员工         |
| creator_id          | bigint       | 非空     | 创建者ID，关联`employee.id`，录入该公司信息的操作员工                 |
| create_time         | timestamp    | 非空     | 创建时间                                                             |
| update_time         | timestamp    | 非空     | 更新时间                                                             |
| is_deleted          | boolean      | 默认false| 逻辑删除标记                                                         |
