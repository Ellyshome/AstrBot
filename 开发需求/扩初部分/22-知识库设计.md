# 22-知识库设计.md

# 一、知识库定位

知识库不是文档仓库。

知识库是：

```text
组织经验资产
```

用于：

```text
查询

复用

总结

决策参考
```

---

# 二、知识库层级

采用三级结构：

```text
KnowledgePackage

↓

Document

↓

Chunk
```

---

# 三、KnowledgePackage

知识包。

示例：

```text
住宅设计导则

工程经验库

供应商资料库

未来城项目知识包
```

---

# 四、Document

知识文档。

来源：

```text
PDF

DOCX

XLSX

Markdown

会议纪要
```

文档保留原文。

禁止修改原始内容。

---

# 五、Chunk

检索单元。

推荐：

```text
500~800 Token
```

切片。

保留：

```text
前后文引用
```

能力。

---

```text
PostgreSQL

```
