# 09-知识库最小实现

## 1. 定位

知识库不是文档仓库，是组织经验资产。

MVP 内置一个默认知识包：

```text
公司制度与业务流程知识包
```

查询涉及公司规定、流程、标准、制度、规章、资料要求时，优先检索该知识包。

---

## 2. 三级结构

```text
KnowledgePackage
  └── Document
        └── Chunk
```

KnowledgePackage：

```text
公司制度与业务流程知识包
项目知识包
设计导则包
工程经验包
```

Document：

```text
来源：PDF、DOCX、XLSX、Markdown、会议纪要
保留原文，禁止修改原始内容
```

Chunk：

```text
检索最小单元
chunk_size: 600
overlap: 120
保留前后文引用
```

---

## 3. Embedding 方案

模型：

```text
BGE-M3
```

存储：

```text
PostgreSQL + pgvector
```

---

## 4. 检索流程

```text
用户提问
→ Embedding
→ 向量检索
→ Top-K = 8
→ 上下文拼接
→ LLM 生成回答
→ 附来源信息
```

---

## 5. 回答来源追溯

所有回答必须返回：

```text
来源知识包
来源文档
来源 Chunk
```

MVP 阶段最少返回文本来源标识。

---

## 6. 知识演化策略

MVP 阶段：

```text
人工导入
```

禁止：

```text
自动知识演化
自动知识融合
自动图谱构建
```

---

## 7. 查询优先检索规则

当用户问题包含以下关键词时，优先检索公司制度与业务流程知识包：

```text
公司规定
制度
流程
规章
规范
标准
要求
依据
按照公司
怎么
如何
需要哪些
需要什么
```
