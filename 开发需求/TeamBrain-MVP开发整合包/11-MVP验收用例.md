# 11-MVP验收用例

## 1. P0 必过用例

### P0-01 插件加载

```text
启动 AstrBot
→ 日志显示 team_brain_agent 插件加载成功
```

---

### P0-02 分域接管

输入：

```text
普通群聊消息，未 @团队大脑
```

期望：

```text
消息可被记录
takeover=false
不回复
不阻断 AstrBot 原主 Agent
```

输入：

```text
@团队大脑 ping
```

期望：

```text
takeover=true
回复"团队大脑已收到"
```

---

### P0-03 事件录入

输入：

```text
@团队大脑 记录一下，今天未来城项目样板段放线完成
```

期望：

```text
messages 新增一条记录
intent=event_record
events 新增一条记录
回复"已记录该事件"
```

---

### P0-04 未绑定用户限制

输入：

```text
未绑定系统的用户 @团队大脑 任务：完成入口整改
```

期望：

```text
messages 入库
回复提示"未绑定系统用户，请先绑定"
不做业务写入
```

---

### P0-05 任务创建

输入：

```text
@团队大脑 任务：王五下周五前完成入口整改
```

期望：

```text
tasks 新增一条记录
title 正确
assignee 正确
回复"已创建任务"
```

---

### P0-06 会议记录

输入：

```text
@团队大脑 会议纪要：本周例会讨论了质量问题，决定下周复查
```

期望：

```text
meetings 新增一条记录
回复"会议纪要已归档"
```

---

### P0-07 文件归档

输入：

```text
@团队大脑 发送文件附件
```

期望：

```text
files 新增一条记录
parse_status=pending
回复"文件已归档"
```

---

### P0-08 制度流程知识包问答

输入：

```text
@团队大脑 按照公司制度，材料进场验收需要提交哪些资料？
```

期望：

```text
QueryApplication 判断需要公司制度依据
优先检索"公司制度与业务流程知识包"
基于检索结果生成回答
```

---

### P0-09 结构化查询

输入：

```text
@团队大脑 未来城项目还有哪些未完成任务？
```

期望：

```text
返回 tasks 表中该项目的未完成任务列表
```

---

### P0-10 回复入库

```text
Agent 回复的内容也应写入 messages
direction=agent_to_user
```

---

### P0-11 异常处理

输入：

```text
模拟数据库不可用
```

期望：

```text
不导致 AstrBot 主流程崩溃
回复"暂时无法处理，请稍后再试"
异常写入日志
```

---

## 2. P1 增强用例

```text
多项目同时使用
项目群绑定自动识别项目
观察模式下只记录不回复
托管模式下全量接管
文件上传后能解析正文并切片进知识包
```

---

## 3. 不通过判定

1. IM 消息无法稳定进入系统。
2. 未接管消息被错误阻断，影响 AstrBot 原主 Agent 或其他插件。
3. 消息不能入库。
4. 业务成功或失败不反馈给用户。
5. 未绑定用户可写入正式业务数据。
6. 异常导致 AstrBot 主流程崩溃。
7. 任务、文件、会议、事件无可追溯记录。
8. 制度流程类问题无法优先检索公司制度与业务流程知识包。
