# 10-最小可跑通开发任务

## 1. 开发顺序

按以下里程碑推进，每一步都是可验收的最小闭环。

```text
M1：插件壳 + 分域接管
M2：消息入库 + 用户映射
M3：Router + 事件录入
M4：任务创建 + 会议记录 + 文件记录
M5：制度流程知识包 + 查询
M6：异常处理 + 验收测试
```

## 8. 第一阶段完成定义

以下全部满足即第一阶段完成：

1. AstrBot Plugin Shell 能加载，不崩溃。
2. 插件能判断接管 / 放行，不阻断 AstrBot 原流程。
3. 所有接管消息能标准化入库。
4. 已绑定用户能录入事件、任务、会议、文件。
5. 未绑定用户不能写正式业务。
6. 能维护公司制度与业务流程知识包。
7. 涉及制度流程的问题优先检索知识包。
8. 能回复用户。
9. 异常可追踪，不导致 AstrBot 主流程崩溃。
