# 06-Intent规则表

## 1. Intent 分类

| Intent | 说明 | 触发优先级 |
|---|---|---|
| file_record | 文件归档 | 最高 |
| query | 查询问答 | 高 |
| task_record | 创建任务 | 中 |
| meeting_record | 会议纪要 | 中 |
| event_record | 记录事件 | 低 |
| chat | 普通聊天 | 最低 |

---

## 2. 优先级解释

```text
file_record > query > task_record > meeting_record > event_record > chat
```

理由：

```text
有附件先归档文件，避免丢失
查询类必须优先区分，避免被"提交、完成"等词误判为任务
任务结构化字段最多，需明确触发
会议通过强关键词直接命中，不受普通优先级影响
事件兜底记录客观事实
chat 最后
```

---

## 3. file_record 规则

触发条件：

```text
消息带附件
上传文件
发送图片
发送文档
```

命中后直接设为 file_record，不再匹配其他 intent。

---

## 4. query 规则

触发关键词：

```text
查询
统计
多少
哪些
帮我查
帮我找
查一下
找一下
公司规定
公司制度
公司要求
按照制度
按制度
制度规定
流程要求
依据
规范
标准
资料
怎么
如何
有没有
什么是
```

命中后优先检索公司制度与业务流程知识包。

---

## 5. task_record 规则

触发关键词：

```text
负责
跟进
完成
整改
处理
落实
提交
安排
分配
指派
任务
截止
}

示例：

```text
王五负责入口整改
```

---

## 6. meeting_record 规则

触发关键词：

```text
会议纪要
会议记录
例会
专题会
评审会
会议：
纪要：
```

强关键词直接命中，优先级高于普通关键词匹配。

---

## 7. event_record 规则

触发关键词：

```text
记录一下
今天完成
现场情况
巡检发现
验收完成
材料到场
样板确认
```

---

## 8. chat 规则

以上均不满足时，统一归类为 chat。

---

## 9. 项目识别规则

| 优先级 | 规则 |
|---|---|
| 1 | 消息中明确出现项目名称（如"未来城""凤凰城""云栖府"） |
| 2 | 当前群绑定的项目 |
| 3 | 用户最近 7 天交互最多的项目 |
| 4 | 无法识别时 project_id 为 None，后续人工确认 |

---

## 10. 分域接管规则

| 条件 | 结果 |
|---|---|
| 单聊中发给机器人的消息 | 接管 |
| 群聊中 @机器人 的消息 | 接管 |
| 命中上述 intent 关键词 | 接管 |
| 配置为托管模式的会话 | 接管 |
| 观察模式下的会话 | 不接管（仅记录） |
| 普通群聊非 @机器人 | 不接管 |
| AstrBot 管理命令 | 不接管 |
