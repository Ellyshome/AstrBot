# 04-接口契约

## 1. StandardMessage

所有 IM 消息进入 TeamBrain Core 前，必须转换为 StandardMessage。

```python
class StandardMessage:
    message_id: str
    platform: str
    conversation_type: str  # private / group
    conversation_id: str
    sender_id: str
    sender_name: str | None
    group_id: str | None
    group_name: str | None
    content: str
    attachments: list[dict]
    is_at_bot: bool
    mentioned_user_ids: list[str]
    reply_to_message_id: str | None
    timestamp: datetime
    raw_event: dict
```

---

## 2. RouteDecision

```python
class RouteDecision:
    takeover: bool
    mode: str              # observe / collaborate / managed
    intent: str | None
    confidence: float
    handler: str | None
    should_reply: bool
    reason: str | None
```

示例：

```json
{
  "takeover": true,
  "mode": "collaborate",
  "intent": "task_record",
  "confidence": 0.91,
  "handler": "task_handler",
  "should_reply": true,
  "reason": "matched_task_keywords"
}
```

未接管示例：

```json
{
  "takeover": false,
  "mode": "collaborate",
  "intent": "chat",
  "confidence": 0.2,
  "handler": null,
  "should_reply": false,
  "reason": "group_message_not_at_bot"
}
```

## 6. TeamBrain Core 入口

```python
class TeamBrainCore:
    async def handle_message(self, message: StandardMessage) -> ReplyMessage | None:
        ...
```

返回 `None` 表示：

```text
不接管
不回复
放行 AstrBot 原流程
```

返回 `ReplyMessage` 表示：

```text
已接管
由 Plugin Shell 发送回复
```
