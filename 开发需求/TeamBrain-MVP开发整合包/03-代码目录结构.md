# 03-代码目录结构

## 1. 正式开发位置

MVP 阶段放在 AstrBot 插件目录：

```text
d:\app\AstrBot\data\plugins\team_brain_agent
```

不要放入：

```text
d:\app\AstrBot\astrbot\core
d:\app\AstrBot\astrbot\builtin_stars
```

## 3. main.py 职责

```text
注册 AstrBot 插件
监听消息事件
调用 inbound_adapter
调用 TeamBrain Core
调用 outbound_sender
```

禁止：

```text
业务规则
数据库读写
Prompt 拼接
向量检索
```

---

## 4. teambrain_core 职责

`teambrain_core` 是未来可独立迁移的业务内核。

禁止直接依赖：

```text
AstrBotMessageEvent
AstrBotContext
AstrBotSession
```

只允许 AstrBot 适配层依赖 AstrBot 原始对象。

---

## 5. MVP 第一批必须创建文件

```text
metadata.yaml
main.py
teambrain_core/bootstrap.py
teambrain_core/config.py
teambrain_core/adapters/astrbot/inbound_adapter.py
teambrain_core/adapters/astrbot/outbound_sender.py
teambrain_core/adapters/standard/message.py
teambrain_core/adapters/standard/route_decision.py
teambrain_core/adapters/standard/reply.py
teambrain_core/application/message_app.py
teambrain_core/services/domain_takeover_service.py
teambrain_core/services/message_service.py
teambrain_core/agents/router_agent.py 或 teambrain_core/application/router.py
```

若暂不单独建 `agents/` 目录，Router 可先放在 application 或 services，但职责必须独立。
