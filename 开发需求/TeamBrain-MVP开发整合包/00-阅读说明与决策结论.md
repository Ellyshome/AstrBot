# 00-阅读说明与决策结论

## 1. 本目录定位

本目录是 TeamBrain 第一阶段 MVP 开发整合包。

它整合了以下资料中的有效内容：

```text
gpt整理需求-提炼版
冻结接口
扩初部分
原始需求讨论结论
```

本目录目标不是继续扩展长期设想，而是支撑下一步进入“最小可跑通功能开发”。

---

## 2. 核心架构决策

采用：

```text
AstrBot Plugin Shell + TeamBrain Core
```

即：

```text
运行上：MVP 阶段以 AstrBot 插件形态启动
架构上：TeamBrain Core 按可独立服务化的业务内核设计
未来：AstrBot 可降级为 IM Gateway，TeamBrain Core 可迁移为独立服务
```

---

## 3. 不采用的方案

MVP 阶段不采用：

```text
纯 AstrBot 普通插件模式
直接夺舍 AstrBot 主 Agent
直接把 AstrBot 全局降级为纯 IM Gateway
直接部署独立 TeamBrain HTTP 服务
多 Agent 协作
复杂 Workflow Engine
Neo4j / GraphRAG
```

---

## 4. 第一阶段目标

第一阶段只跑通最小闭环：

```text
IM 消息进入 AstrBot
→ Plugin Shell 接收
→ 转换为 StandardMessage
→ TeamBrain Core 判断接管 / 放行
→ 接管消息写入 messages
→ Router 识别 intent
→ 执行最简单 Handler 或 Query
→ 生成 ReplyMessage
→ Plugin Shell 发送 IM 回复
```
