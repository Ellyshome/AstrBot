# 13-代码模块与文件结构设计

本文件用于指导第一阶段代码落地，只定义模块、目录、文件职责和依赖边界，不规定具体函数实现。

---

## 3. main.py

职责：

```text
AstrBot 插件入口
接收 AstrBot 消息事件
调用 team_brain.integrations.astrbot.adapter 标准化
调用团队大脑处理入口
调用 sender 回复
```

禁止：

```text
写业务逻辑
直接写数据库
直接拼 SQL
直接调用具体 Handler
```

---

## 4. config.py / bootstrap.py

`config.py`：

```text
读取数据库、存储、日志、开关配置
```

`bootstrap.py`：

```text
初始化数据库连接
初始化服务对象
初始化 Router Agent
```

---

## 5. common

通用能力：

```text
ids.py：生成 event_id、任务编号、文件编号
logger.py：统一日志
exceptions.py：统一异常
```

---

## 6. schemas

定义系统内部标准对象。

```text
im.py：StandardIMMessage
intent.py：IntentResult
route_decision.py：接管 / 放行决策结果
reply.py：ReplyMessage
```

Handler 和 Agent 只依赖 schemas，不依赖 AstrBot 原始对象。

---

## 7. integrations/astrbot

`adapter.py`：

```text
AstrBot 原始消息 → StandardIMMessage
```

`sender.py`：

```text
封装 AstrBot 回复能力
```

`user_mapper.py`：

```text
根据 im_platform + im_user_id 查找系统用户
```

---

## 8. agents

`router_agent.py`：

```text
判断 intent
分派到 Handler / Query Agent
```

`query_agent.py`：

```text
处理查询类请求
组织查询结果回复
```

Agent 不直接写数据库。

---

## 9. handlers

Handler 处理具体业务意图。

```text
event_handler.py：事件录入
file_handler.py：文件上传
meeting_handler.py：会议记录
task_handler.py：任务创建
```

Handler 调用 Service，不直接操作数据库连接。

---

## 10. services

Service 执行业务规则。

示例：

```text
message_service.py：消息入库
event_service.py：事件记录
file_service.py：文件元数据
meeting_service.py：会议记录
task_service.py：任务创建
query_service.py：查询，负责判断是否需要制度流程依据并优先检索知识包
domain_takeover_service.py：根据会话模式、@状态、业务关键词、项目群配置判断接管或放行
knowledge_package_service.py：公司制度、规章、既定流程知识包管理与切片入库
archive_service.py：归档协调
```

---

## 11. infrastructure

基础设施封装。

## 14. 禁止事项

1. 禁止在 main.py 中直接写业务逻辑。
2. 禁止 team_brain_agent 直接夺舍或替换 AstrBot 主 Agent。
3. 禁止 MVP 阶段把 AstrBot 全局降级为纯 IM Gateway。
4. 禁止在 Agent 中直接拼 SQL。
5. 禁止 Handler 直接依赖 AstrBot 原始对象。
6. 禁止数据库模型与 IM 原始 payload 强耦合。
7. 禁止第一阶段创建大量空目录。
8. 禁止为了未来可能性提前拆微服务。
9. 禁止绕过 Service / Repository 直接跨层调用。

---

## 15. 结论

第一阶段代码结构应服务于快速闭环，而不是追求完整平台化。

核心边界：

```text
plugin 接入
adapter 标准化
domain_takeover 判断接管/放行
router 分派
handler 处理
service 规则
repository 入库
sender 回复
```
