# 01-项目目标与MVP范围

## 1. 项目目标

团队大脑 Agent 系统面向商品住宅项目开发全过程，目标是通过 IM 与用户自然交互，帮助团队完成信息录入、查询、核验、任务提醒和知识沉淀。

第一阶段不建设完整企业数字大脑，而是先实现可真实使用的 MVP。

---

## 2. 当前业务背景

项目业务覆盖：

```text
拿地
规划设计
报建报批
土建施工
材料进场
会议协调
任务推进
交付结算
资料归档
```

当前最需要解决的问题：

```text
信息分散在 IM 群里
文件难以追溯
会议任务容易遗漏
项目事件缺少结构化记录
历史资料难查询
```

---

## 3. MVP 核心价值

MVP 要先证明：

```text
用户可以继续在 IM 里工作
系统能自动留下结构化记录
后续可以查询和追踪
```

不是先证明：

```text
系统能自动决策
系统能自动审批
系统能自动生成企业标准
```

---

## 4. MVP 主入口

第一阶段主入口为：

```text
AstrBot / IM
```

支持来源优先级：

```text
QQ / 企业微信等 AstrBot 已支持平台
```

Web / FastAPI 可作为后续管理接口，不作为第一阶段主入口。

---

## 5. MVP 必须实现

| 能力 | 说明 |
|---|---|
| IM 消息接入 | AstrBot 将消息交给团队大脑模块 |
| 分域接管 | 命中团队大脑业务域时接管，未命中时放行给 AstrBot 原流程 |
| 消息入库 | 所有消息写入 messages |
| 用户映射 | IM 账号映射系统用户 |
| 项目基础 | 支持基础项目记录与项目成员关系 |
| 事件录入 | 从 IM 记录项目事件 |
| 文件记录 | 上传文件形成元数据 |
| 制度流程知识包 | 维护公司规章制度、既定业务流程等文件仓库，并支持 RAG 检索 |
| 会议记录 | 会议纪要文本或文件入库 |
| 任务创建 | 从 IM 文本创建任务 |
| 简单查询 | 查询任务、文件、会议、事件；当问题需要公司制度或流程依据时，优先检索制度流程知识包 |
| IM 回复 | 成功/失败结果回发用户 |
| 审计日志 | 关键操作可追踪 |

---

## 6. MVP 暂不实现

```text
复杂审批
完整流程引擎
完整状态机
复杂 RBAC
多 Agent 协同
知识图谱
自动标准生成
ERP/OA/CAD/BIM 集成
微服务部署
```

---

## 7. 第一阶段成功标准

满足以下条件即可进入内部试运行：

1. 用户可通过 IM 发送消息给系统。
2. 系统能记录所有消息。
3. 系统能识别事件、文件、会议、任务、查询等基础意图。
4. 系统能写入对应业务表。
5. 用户能收到明确回复。
6. 基础查询可用。
7. 公司制度、规章、既定业务流程类资料可以作为知识包被优先检索。
8. 异常可追踪，不影响 AstrBot 主流程。

---

## 8. MVP 后的扩展方向

MVP 跑通后，按以下顺序扩展：

```text
计划任务提醒
文件解析与向量化
多轮信息补全
权限细化
LangGraph 工作流
自进化业务流审核
Neo4j 知识图谱
事件总线
```
