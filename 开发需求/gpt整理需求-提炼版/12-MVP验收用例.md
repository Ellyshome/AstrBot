# 12-MVP验收用例

## 1. 验收目标

确认系统可以通过 AstrBot / IM 入口进入内部试运行。

---

## 2. P0 必过用例

### P0-01 消息接入

输入：

```text
你好
```

期望：

```text
AstrBot 将消息传入团队大脑
生成 event_id
写入 messages
```

---

### P0-02 群聊普通消息

输入：

```text
大家明天上午现场集合。
```

期望：

```text
写入 messages
conversation_type = group
不误触发业务
默认不刷屏回复
```

---

### P0-03 分域接管与放行

输入：

```text
普通闲聊消息，且未 @ 团队大脑
```

期望：

```text
团队大脑插件可记录消息
判断为不接管
不阻断 AstrBot 原主 Agent / 其他插件流程
```

输入：

```text
@团队大脑 查一下未来城项目未完成任务
```

期望：

```text
团队大脑插件判断为接管
交给 TeamBrain Router Agent
不再交给 AstrBot 原主 Agent 生成重复业务回复
```

---

### P0-04 事件录入

输入：

```text
记录一下，今天未来城项目1号楼地下室防水验收完成。
```

期望：

```text
intent = event_record
写入 events
回复已记录
```

---

### P0-05 未绑定用户限制

输入：

```text
记录一下，今天材料进场验收完成。
```

前提：发送人未绑定系统用户。

期望：

```text
messages 入库
不写正式业务数据
回复绑定提示
```

---

### P0-06 任务创建

输入：

```text
任务：王五下周五前完成未来城项目1号楼入口整改。
```

期望：

```text
intent = task_record
写入 tasks
owner_text = 王五
回复任务编号
```

---

### P0-07 会议记录

输入：

```text
会议纪要：未来城项目工程例会，王五负责周五前完成入口整改。
```

期望：

```text
intent = meeting_record
写入 meetings
可选生成 tasks
回复会议编号
```

---

### P0-08 文件上传

输入：

```text
上传未来城项目工程例会纪要.docx
```

期望：

```text
写入 messages
写入 files
回复文件编号
```

---

### P0-09 查询未完成任务

## 输入

```text
查一下未来城项目还有哪些未完成任务？
```

期望：

```text
intent = query
查询 tasks
回复任务列表或暂无任务
```

---

### P0-10 制度流程知识包问答

前提：

```text
已上传至少一份公司制度或既定业务流程文件
该文件已关联“公司制度与业务流程知识包”
该文件已生成 document_chunks
```

输入：

```text
按照公司制度，材料进场验收需要提交哪些资料？
```

期望：

```text
intent = query
系统判断该问题需要公司制度或流程依据
优先检索公司制度与业务流程知识包
回答中基于库内资料生成结论
如能定位来源，返回制度或流程文件名称
```

---

### P0-11 回复入库

触发任意成功业务。

期望：

```text
用户收到回复
回复也写入 messages
direction = agent_to_user
```

---

### P0-12 异常处理

模拟数据库写入失败。

期望：

```text
捕获异常
写日志 / events(system_error)
回复失败提示
AstrBot 主流程不崩溃
```

## 4. 不通过判定

任一情况出现，不建议试运行：

1. IM 消息无法稳定进入系统。
2. 未接管消息被团队大脑插件错误阻断，影响 AstrBot 原主 Agent 或其他插件。
3. 消息不能入库。
4. 业务成功或失败无反馈。
5. 未绑定用户可写正式业务。
6. 异常导致 AstrBot 主流程崩溃。
7. 任务、文件、会议、事件无可追溯记录。
8. 制度流程类问题无法优先检索公司制度与业务流程知识包。

---

## 5. 试运行通过标准

P0 全部通过即可进入内部试运行。
