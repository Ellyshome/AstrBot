# 02-术语与统一命名

## 1. 目的

本文件统一团队大脑系统中的核心概念，避免需求、数据库、代码中出现多套命名导致理解混乱。

---

## 2. 命名分层原则

系统采用两层命名：

```text
领域层命名：用于业务理解和架构说明
数据库层命名：用于表结构和代码实现
```

示例：

```text
领域层：Person
数据库层：users
```

---

## 3. 核心术语对照

| 领域概念 | 数据库/代码建议 | 说明 |
|---|---|---|
| Person | users | 系统识别的人或账号 |
| Company | companies | 组织、单位、供应商、施工单位等 |
| Project | projects | 项目容器 |
| Conversation | conversations | IM 单聊或群聊会话 |
| Message | messages | 一条 IM 消息 |
| File | files | 文件元数据，文件本体在 MinIO 或本地存储 |
| Meeting | meetings | 会议记录或会议纪要 |
| Task | tasks | 需要执行和追踪的工作项 |
| Event | events | 系统可追溯事件记录 |
| KnowledgePackage | knowledge_packages | 公司制度、规章、既定业务流程等资料集合 |
| KnowledgeChunk | document_chunks | MVP 先做文档切片，支撑知识包检索 |

---

## 4. Person 与 User

长期领域中可称为 Person，但 MVP 数据库统一使用：

```text
users
```

含义：

```text
可以登录、被绑定 IM、参与项目、创建任务或触发事件的系统用户
```

外部人员如果还未绑定系统账号，可以先只记录 IM 身份，不能直接作为正式业务责任人。

---

## 5. Conversation 与 Message

Conversation 表示会话：

```text
一个群聊
一个单聊
一个持续上下文
```

Message 表示消息：

```text
用户发来的一条文本
上传的一个文件消息
Agent 回复的一条消息
```

关系：

```text
Conversation 1:N Message
```

---

## 6. Event 与 Task

Event 表示已经发生的事情。

例如：

```text
文件已上传
会议已记录
材料已进场
任务已创建
```

Task 表示需要执行的事情。

例如：

```text
王五下周五前完成整改
张三提交材料清单
```

关系：

```text
Event 可以触发 Task
Task 完成也会产生 Event
```

---

## 7. Handler 与 Agent

MVP 不把所有业务处理都做成 Agent。

| 类型 | 定位 |
|---|---|
| Router Agent | 识别意图并分派 |
| Query Agent | 查询和问答入口 |
| Handler | 处理具体业务意图，如任务、会议、文件、事件 |
| Service | 执行业务规则和数据写入 |
| Repository | 封装数据库操作 |

---

## 8. Archive Agent 与 Archive Service

原文档中 Archive Agent / 内业 Agent / 归档 Agent 概念接近。

MVP 统一为：

```text
Archive Service
```

职责：

```text
写入文件元数据
写入消息记录
写入事件记录
维护归档关系
```

后续可升级为 Archive Agent。

---

## 9. ID 命名建议

MVP 可使用 UUID 作为主键。

业务可读编号建议：

```text
EV-YYYYMMDD-000001：入口事件 ID
MSG-YYYYMMDD-000001：消息编号，可选
FILE-YYYYMMDD-000001：文件编号
TASK-YYYYMMDD-000001：任务编号
MEET-YYYYMMDD-000001：会议编号
```

---

## 10. 结论

开发实现时，数据库和代码优先采用复数英文表名：

```text
users / projects / conversations / messages / files / meetings / tasks / events
```

文档说明中可以使用 Person / Project / Event 等领域概念，但必须能映射到数据库层命名。
